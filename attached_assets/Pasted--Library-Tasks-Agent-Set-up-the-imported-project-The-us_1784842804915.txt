Plan #4 - Add per-game CPU/GPU boost profiles for BGMI, PUBG, and Free Fire
#4 - Add per-game CPU/GPU boost profiles for BGMI, PUBG, and Free Fire
What & Why
Currently all gaming optimizations are applied globally. A smarter approach is an init.d script that detects specific game package names and applies targeted CPU/GPU/network boosts (uclamp, cpu affinity, SCHED_FIFO, TCP socket buffer tuning) only while the game is active — improving battery life outside of gaming sessions.

Done looks like
anykernel3/fogos_gaming_init.sh is extended with per-app profiles for:
com.pubg.imobile (BGMI)
com.tencent.ig (PUBG Mobile)
com.dts.freefireth (Free Fire)
Script hooks into Android's am broadcast or app_process to detect foreground app
CPU governor switches to performance + uclamp 100% when game is foreground, schedutil when idle
Relevant files
anykernel3/fogos_gaming_init.sh — existing init.d gaming script
anykernel3/anykernel.sh — handles installing the script to /system/etc/init.d/
